# 图表设计依据

2026-10-22 实际打开 [AgentCgroup v3 论文 PDF](https://arxiv.org/pdf/2602.09345v3)，核对第 2、3、4、6 页中的全部 8 幅图。

| 原论文图号 | 实际画法与用途 |
| --- | --- |
| 1 | 任务总耗时直方图、执行阶段占比堆叠柱状图 |
| 2 | 两幅饼图：工具类别总耗时占比、Bash 命令类别耗时占比；不是逐次工具时延曲线 |
| 3 | 工具耗时占比直方图、按归一化执行进度统计工具调用数的堆叠面积图 |
| 4 | 镜像大小直方图、归一化执行进度上的平均内存曲线和分位带 |
| 5、6 | CPU、内存时间序列，上下排列并使用相同时间范围，标记工具调用区间 |
| 7 | CPU 和内存变化率直方图，频数轴采用对数刻度 |
| 8 | 两组柱状对照：OOM 存活率、分配时延 P95 |

## 本仓库采用的画法

| 数据与问题 | 呈现方式 |
| --- | --- |
| 每次工具调用用了多久 | 按调用序号画柱状图，每根柱子是一次调用的总耗时；调用少时直接标数值。执行区间与总耗时分开表达 |
| 一个任务的内存如何变化 | 约 200 ms 的 cgroup 连续采样画时间曲线，标出工具、扫描暂停及已有的异步等待区间 |
| 每轮暂停后有多少文件页驻留 | Page Cache 画 N+1 个实际扫描点，不插值。扫描驻留与 cgroup 文件页计费口径不同，后者保留在数据表中 |
| 十个任务的工具时延有何差异 | 用中位数、P95、最大值的点图对比，并标调用数；相差多个数量级时采用对数时间轴 |
| 十个任务的内存与缓存量级 | 内存峰值横向柱状图；文件缓存初始、峰值、结束驻留量点图 |
| CompCert 两种限额的差异 | 并列配置，共用各指标的单位和数值范围；时延按调用序号，内存与缓存按测量墙钟 |

论文不提供 Page Cache 曲线。本仓库按实际采集粒度选择图型，采用其“资源曲线关联工具区间”的表达方式，不将所有指标强行放到一种横轴上。单次运行也不足以照搬跨多任务的分位带，图中不构造重复实验误差范围。

完整墙钟图保留测量暂停。去除暂停的辅助图只是显示变换：内存样本仍保留，暂停期间样本显示为灰点，不能当作无测量干扰的运行性能。
